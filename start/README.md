# Zestaw startowy: praca z agentem nad stronami z ruchem

Wnioski z projektu Wir Studio (odwzorowanie cappen.com, 8–11.10.2026), przygotowane tak, żeby nowy agent wiedział, skąd
czerpać i jak pracować, bez czytania całej historii.

| Plik | Do czego |
|---|---|
| `zasady-ogolne.md` | Wnioski przenośne: jak pracujemy (dwie ścieżki, testy według ryzyka), telefon i Chrome, ułatwianie przewijania, przejścia kolorów i warstw, responsywność u źródła, efekty, jak nie psuć innych sekcji, narzędzia |
| `CLAUDE-szablon.md` | `CLAUDE.md` dla nowego projektu: zasady pracy z Grzegorzem, ścieżki A i B, sprawdzanie, miejsca do uzupełnienia |
| `prompt-nowa-strona.md` | Pierwsza wiadomość do agenta w nowym folderze: nowa strona do odwzorowania |
| `prompt-sekcja.md` | Pierwsza wiadomość, gdy strona już jest i dodajemy albo zmieniamy sekcję |
| `prompt-pagespeed.md` | Pierwsza wiadomość na etap wydajności (PageSpeed i płynność na telefonie) |

**Zasada utrzymania:** wniosek, który sprawdził się w projekcie i pasuje do każdej strony, dopisać do
`zasady-ogolne.md` (krótko, z powodem). Wniosek dotyczący jednej strony zostaje w jej `wiedza/lekcje.md`.
